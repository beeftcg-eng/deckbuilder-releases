# Deckbuilder — downloads

Desktop deckbuilder for Riftbound, One Piece Card Game and Pokémon TCG: card browser, legality checks, collection and wishlist tracking, and export. This repo only hosts the downloadable installers.

**Windows:** download `Deckbuilder-Setup.exe` from the [latest release](../../releases/latest) and run it.

Windows may show a blue "Windows protected your PC" screen because the installer isn't code-signed. Click **More info → Run anyway**.

On first launch, pick a game in the sidebar and click **Sync card data** (Pokémon has ~20k cards and can take a couple of minutes). To send wishlist cards to your Pawmodoro checklist, open the Wishlist panel and create an account with an email and password — it's already connected to the shared Pawmodoro cloud.
